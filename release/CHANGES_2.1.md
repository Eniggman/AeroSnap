# AeroSnap 2.1

AeroSnap 2.1 — крупное обновление стабильности, точности кадрирования и производительности.

- **High-DPI Масштабирование**: исправлена нарезка скриншотов и захват видео на мониторах с масштабированием 125%–200% (4K, 2K, ноутбуки). Координаты оверлея теперь идеально точно совмещаются с физическим буфером дисплея.
- **Очистка ресурсов MediaStream**: гарантированная остановка всех системных потоков захвата экрана и таймеров при закрытии/отмене оверлея захвата.
- **Изоляция горячих клавиш**: клавиша Escape теперь обрабатывается исключительно внутри окна оверлея и больше не перехватывается глобально во всей операционной системе.
- **Стабильность выключения Windows**: исправлен перехват события before-quit, окно настроек больше не блокирует перезагрузку и выключение ПК.
- **Отказоустойчивость файловой системы**: системный диалог и команда открытия папок автоматически создают целевую директорию, если она отсутствует.
- **Синхронизация IPC и настроек**: окно настроек корректно разворачивается из свёрнутого состояния (unminimize), исправлены сигнатуры сохранения снимков и мосты Preload.

Проверено: 7 модульных тестов Rust (cargo test), cargo check, синтаксис JavaScript и NSIS release build (AeroSnap-2.1-windows-x64-setup.exe).
