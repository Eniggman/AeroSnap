# AeroSnap 2.3

AeroSnap 2.3 — обновление горячих клавиш, автозагрузки Windows и оформления настроек:

- **Разделение горячих клавиш скриншотера и видеозаписи**:
  - PageUp по умолчанию — исключительно скриншотер. В режиме скриншота кнопки видеозаписи и GIF автоматически скрываются из панели оверлея, предотвращая случайный запуск записи.
  - Home по умолчанию — запуск и остановка видеозаписи.
  - Insert (Ins) по умолчанию — пауза / возобновление записи видео.
  - В настройках теперь 3 независимых поля ввода хоткеев с поддержкой стирания по Backspace/Delete, кнопкой «×» и семантической валидацией конфликтов сочетаний.
  - Поддержка ввода хоткеев на любой раскладке клавиатуры (русская / английская).
- **Аудит автозагрузки Windows**:
  - Двусторонняя синхронизация галочки автозапуска с реестром HKCU\Software\Microsoft\Windows\CurrentVersion\Run.
  - Принудительная актуализация пути к исполняемому файлу AeroSnap с аргументом --background.
- **Контрастная тёмная подложка иконки в настройках**:
  - Оформление контейнера логотипа (.brand-icon) в боковой панели настроек на глубоком графитовом градиенте с тонким контуром — иконка выглядит сочно и не сливается со светлым фоном интерфейса.
  - Системные иконки трея и приложения сохранены без изменений.
- **Стабильность и авто-восстановление**:
  - 18 автоматических unit-тестов в Rust (cargo test).
  - Автоматическое восстановление корректных значений по умолчанию при повреждении конфигурационного файла.
