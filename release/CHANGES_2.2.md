# AeroSnap 2.2

AeroSnap 2.2 — крупное архитектурное обновление: полный переход на нативный Core Tauri 2.0 и стабилизация жизненного цикла видеозаписи.

- **Вычитание пауз из видео (Timestamp Compensation)**: пауза теперь корректно вырезает время простоя из потока энкодера MP4 и UI-таймера — видео не зависает на месте паузы.
- **Атомарная State Machine записи (Idle → Starting → Active)**: устранена возможность race condition и повторного старта захвата при быстрых двойных кликах.
- **Выборочное кодирование форматов**: создание только выбранного формата (MP4 или GIF) снижает нагрузку на CPU/RAM в 2 раза при захвате 2K/4K.
- **Блокировка конфликтов**: исключен вызов оверлея скриншота во время активной видеозаписи.
- **Чистый тулчейн Tauri 2.0**: полностью удален устаревший легаси Electron-стек (src/main, src/preload), проект переведён на нативную легковесную архитектуру.
- **High-DPI Масштабирование**: идеальное кадрирование скриншотов на мониторах 125%–200%.
- **Сброс счётчика нумерации**: шаги (1, 2, 3...) автоматически начинают нумерацию с единицы при каждом новом открытии оверлея.
- **Изоляция хоткеев**: клавиша Escape работает только внутри активного оверлея.

Проверено: 8 модульных тестов Rust (cargo test), cargo check, синтаксис JavaScript и NSIS release build (AeroSnap-2.2-windows-x64-setup.exe).
