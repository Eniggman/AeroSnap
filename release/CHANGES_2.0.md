# AeroSnap 2.0

AeroSnap 2.0 продолжает существующее Tauri-приложение версии 1.9.

- Исправлено сохранение настроек: обязательные, старые и неизвестные будущие поля больше не теряются.
- Регистрация горячих клавиш стала транзакционной: при ошибке возвращается предыдущая рабочая комбинация.
- Зелёная кнопка открывает системное окно «Сохранить как» с выбранным PNG/JPG, предложенным именем и папкой из настроек.
- Отмена диалога оставляет редактор открытым; после успешной записи открывается выбранная папка.
- Пиксельная мозаика заменена настоящим Gaussian blur с мягкой маской для прямоугольника и кисти.
- Диаметр кисти размытия связан с существующим выбором толщины; Undo, Redo и очистка используют общую историю.
- Обновлены монохромные иконки прямоугольного и рисуемого размытия.
- Все активные поверхности Tauri-приложения и Windows-файлы синхронизированы с версией 2.0.0.

Проверено: JavaScript syntax check, `cargo fmt --check`, `cargo check`, 5 модульных тестов и NSIS release build. Один тест живого захвата экрана намеренно пропущен как интерактивный. Установщик не подписан цифровым сертификатом.
