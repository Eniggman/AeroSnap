# AeroSnap 2.0

AeroSnap — лёгкое приложение для скриншотов и записи экрана на Windows, вдохновленно с приложения skrinshoter.ru

## Возможности

- захват выбранной области экрана;
- аннотации: карандаш, стрелки, прямоугольники, нумерация и текст;
- прямоугольное и рисуемое Gaussian-размытие;
- Undo, Redo и очистка аннотаций;
- системный диалог «Сохранить как» для PNG/JPG;
- копирование результата в буфер обмена;
- трей, глобальные горячие клавиши и настройки автозапуска.

## Сборка

Требуются Rust, Windows WebView2 и Node.js с установленным Tauri CLI.

```powershell
npm install
npm run tauri:build
```

## Публикация

Готовый установщик находится в `release/`. Контрольная сумма — в `release/SHA256SUMS.txt`, изменения — в `release/CHANGES_2.0.md`.

Проект не содержит пользовательских скриншотов, профилей, секретов или абсолютных путей разработки. Установщик не подписан цифровым сертификатом.
