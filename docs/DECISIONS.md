# Архитектурные и технические решения: AeroSnap 2.1

## 1. Стек технологий

- **Целевой нативный Core Runtime**: Tauri 2.0 (Rust) — аппаратное кодирование H.264 MP4 через Windows Media Foundation, нативный захват экрана через `xcap` и `windows-capture`, размер дистрибутива 1.6 МБ и 0% CPU в фоне.
- **Поддержка High-DPI (v2.1)**: Логические координаты оверлея из Webview автоматически масштабируются на `scale_factor` дисплея при нарезке буферов в `capture.rs` и `recording.rs`, обеспечивая попиксельную точность на экранах 125%–200%.
- **Стилизация и UI**: Vanilla CSS + Glassmorphism / Frutiger Aero — полупрозрачные стеклянные панели (`backdrop-filter`), сочные аква-градиенты, плавные отклики и анимации.
- **Инструмент «Размытие водой» (Liquid Blur)**: Иконка в виде пунктирной капли воды Frutiger Aero (`stroke-dasharray="3 2"`) для кисти и рамки размытия, подчёркивающая эффект скрытия/блюра.
- **Режим «Живой выбор» (Live Transparent Overlay)**: Окно оверлея открывается полностью прозрачным и не замораживает рабочий стол на старте. Рабочий стол остаётся живым во время выбора, а снимок и обрезка выделенной области `(x, y, w, h)` выполняются моментально в момент нажатия «Копировать» или «Сохранить».
- **Мгновенный старт видеозаписи**: Нативный захват экрана без лагов и скачков FPS с поддержкой аннотаций, паузы/возобновления и экспорта в MP4 и GIF.
- **Звуковой движок (Web Audio API)**: Полноценный синтезатор звука на Web Audio API (`src/renderer/sound.js`): мягкие кристальные восходящие/нисходящие колокольчики Frutiger Aero при старте и завершении видео, скриншоты — бесшумно.

## 2. Архитектура панелей оверлея (AeroSnap v2.1)

- **Вертикальная панель действий (прижата к правому нижнему краю рамки):**
  1. `[ 💾 Сохранить ]` (Сохранение скриншота в файл через системный диалог)
  2. `[ 🎞️ GIF ]` (Запись GIF-анимации)
  3. `[ 📹 Видео ]` (Запись MP4-видео)
  4. `[ 📋 Скопировать ]` (Копирование в буфер обмена — в самом низу)
- **Горизонтальная панель инструментов (строго по центру под рамкой):**
  - Инструменты: ✏️ Карандаш | ↗️ Стрелка | ⏹️ Прямоугольник | 🔤 Текст | ① Счетчик | 💧 Размытие кисть | 💧 Размытие область.
  - Управление: ↩️ Отмена | ↪️ Повтор | 🗑️ Очистить всё.
  - Настройки кисти: Толщина линии (2px/4px/7px/12px) | Палитра цветов.
  - Завершение: `[ ❌ Закрыть ]` (в самом конце горизонтальной панели).
- **Управление рамкой:**
  - Перетаскивание: зажатием мыши прямо за пунктирные границы рамки (`cursor: move`).
  - Изменение размера: 8 маркеров по периметру.
- **Горячие клавиши (свободно переназначаются пользователем в Настройках):**
  - `Скриншот / выбор области (Скриншот, Видео, GIF)`: по умолчанию **`Pause`**.
  - `Пауза / Возобновление записи видео`: по умолчанию **`ScrollLock`**.
  - `Escape`: изолирован внутри активного окна оверлея, не перехватывает глобальный фокус в других приложениях ОС.

## 3. Оптимизация производительности и фонового режима (0% CPU в фоне)

- **Фоновый старт по умолчанию**: При запуске программа тихо садится в трей без выскакивания окна настроек.
- **Чистый нативный Core Tauri 2.0**: Полный отказ от легаси-зависимостей Electron (`src/main`, `src/preload`, `electron-builder`) в пользу сверхлёгкого бинарника Rust.
- **Компенсация пауз при записи (Timestamp Compensation)**: При паузе видео накопленная длительность простоя вычитается из таймкодов кадров Windows Graphics Capture и UI-таймера, исключая зависания кадров в MP4.
- **Атомарная State Machine записи (`Idle` → `Starting` → `Active`)**: Защита от race conditions и повторного запуска захвата при быстрых двойных кликах.
- **Выборочное кодирование форматов**: Инициализация только выбранного энкодера (MP4 или GIF) снижает нагрузку на CPU/RAM при захвате 2K/4K.
- **Мгновенное освобождение памяти**: При закрытии оверлея захвата (`closeOverlay`), все медиа-потоки `MediaStream` гарантированно останавливаются, а пиксельные буферы canvas сбрасываются.
- **Автозапуск Windows**: Нативная регистрация в автозагрузке Windows через `tauri-plugin-autostart`.

## 4. Архитектура модулей

- `src-tauri/src/lib.rs` — Точка входа Tauri 2.0, системный трей, регистрация горячих клавиш, IPC хэндлеры.
- `src-tauri/src/capture.rs` — Захват экрана `xcap`, кадрирование с учётом High-DPI масштабирования, работа с буфером обмена и диалогами сохранения.
- `src-tauri/src/recording.rs` — Высокопроизводительный нативный захват экрана `windows-capture`, аппаратное сжатие H.264 (WMF) и GIF-кодирование.
- `src-tauri/src/settings.rs` — Атомарное сохранение и загрузка настроек (`aerosnap-config.json`).
- `src/renderer/tauri-bridge.js` — Мост между фронтендом и нативным бэкендом Tauri.
- `src/renderer/sound.js` — Синтезатор звуков на Web Audio API (бархатные кристальные колокольчики).
- `src/renderer/overlay.js` / `overlay.html` / `overlay.css` — Оверлей выбора и аннотаций с двумя раздельными стеклянными панелями.
- `src/renderer/settings.html` / `settings.js` — Окно настроек с поддержкой переназначения хоткеев кликом по полю ввода.
- `src/renderer/frutiger-aero.css` — Дизайн-система Frutiger Aero & Liquid Glass.

## 5. Файловая система и именование

- **Каталоги по умолчанию:**
  - Скриншоты: `Pictures/AeroSnap/Screenshots/`
  - Видеозаписи и GIF: `Pictures/AeroSnap/Videos/`
- **Шаблон автоименования:**
  - `AeroSnap_ГГГГ-ММ-ДД_Номер.расширение` (например, `AeroSnap_2026-08-19_1.png`, `AeroSnap_2026-08-19_2.mp4`).
  - Умное сканирование: поиск максимального индекса за текущие сутки для предотвращения перезаписи.
